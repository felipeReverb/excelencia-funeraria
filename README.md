# Excelencia Funeraria

Presentación estática de servicios funerarios en CDMX y Estado de México.

Sitio: https://felipereverb.github.io/excelencia-funeraria/

Publicación: GitHub Pages, rama main, carpeta raíz. HTML, CSS y JavaScript, sin instalación de dependencias. Los archivos de este repositorio son la versión publicable. El formulario prepara un mensaje en WhatsApp para revisión y envío por el visitante.

La presentación permanece con noindex. El aviso de privacidad, logotipo definitivo y analítica están pendientes de aprobación/configuración.
